## Key Files (Where to Look)

### 1. Core Logic

**spimidiarpeggiator_polywin32.cpp**

- Location: Source Files
- Implements:
- `_tWinMain` startup, command-line parsing, window initialization
- MIDI I/O setup using PortMidi/PortTime
- WinMM timer scheduling for arpeggio timing
- Global state variables for window, font, MIDI streams, tempo, program, and layout
- UTF-8/Wide string conversion utilities

### 2. Precompiled Headers & SDK Targeting

**stdafx.h / stdafx.cpp**

- Purpose: Build a precompiled header (PCH) to speed up compilation of Windows and CRT headers.
- stdafx.h includes `targetver.h` and core Windows and CRT headers.
- stdafx.cpp includes only `stdafx.h` to generate the PCH.

**targetver.h**

- Purpose: Defines the highest Windows SDK version by including `SDKDDKVer.h`.
- Modify here if you need to target an earlier Windows platform.

### 3. Win32 Resources

**spimidiarpeggiator_polywin32.rc**

- Location: Resource Files
- Contains:
- Dialog definitions (About box, accelerators)
- Icon, cursor, bitmap, and menu resources loaded by the application

**Resource.h**

- Location: Header Files
- Defines numeric IDs for all resources referenced in the .rc file (e.g., IDC_MAIN_EDIT, IDC_MAIN_STATIC).

### 4. Project Configuration & Filters

**spimidiarpeggiator_polywin32.vcxproj**

- Defines four configurations: Debug/Win32, Debug/x64, Release/Win32, Release/x64
- Uses PlatformToolset `v141` (Visual Studio 2017)
- Configures:
- Preprocessor definitions (`WIN32`, `_DEBUG`, `_WINDOWS`, `NDEBUG`)
- AdditionalIncludeDirectories for FreeImage, PortAudio, PortMidi, spiwavsetlib
- Linker AdditionalDependencies for FreeImage.lib, winmm.lib, portaudio_x86/x64.lib, portmidi-dynamic.lib, spiwavsetlib_vs2017.lib

**spimidiarpeggiator_polywin32.vcxproj.filters**

- Groups files in the IDE under:
- **Source Files** (`.cpp`, `.c`, etc.)
- **Header Files** (`.h`, `.hpp`, etc.)
- **Resource Files** (`.rc`, `.ico`, `.png`, etc.)
- Ensures that `ReadMe.txt` and icons appear under Resource Files, and that source/header files are properly categorized.
